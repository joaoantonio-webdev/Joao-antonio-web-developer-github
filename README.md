# 🚀 Hub de Negócios & Comunidade — João Antônio

Bem-vindo ao repositório oficial do meu hub de negócios e central de atendimento. Este projeto foi desenvolvido com foco em alta performance, design responsivo e integração direta com ferramentas de comunicação.

## 🎨 Paleta de Cores do Projeto
- **Azul Principal & Azul-Marinho:** Transmitem seriedade, tecnologia e confiança.
- **Branco:** Organização, clareza e limpeza visual.
- **Amarelo:** Destaque para chamadas de ação (CTA) e pontos de conversão.

## 📂 Estrutura do Site
- **Hub:** Página inicial de apresentação corporativa e portfólio de soluções.
- **Serviços de Demonstração:** Vitrine dos serviços profissionais oferecidos.
- **Feedbacks:** Central de avaliações integrada via **Discord Webhooks** (os envios caem diretamente no canal da diretoria em tempo real).

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização moderna com variáveis e design responsivo)
- **JavaScript (Vanilla)** (Manipulação de abas e integração assíncrona com API de Webhooks)
